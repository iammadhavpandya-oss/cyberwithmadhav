3.13.01

Radio basics: bands, channels and names

Wi-Fi is half duplex radio: on one channel only one device transmits at a time, and everyone else waits. Good design is mostly about giving each area a clean channel.

Wi-Fi bands
BandStrengthsWeaknesses
2.4 GHzLonger range, passes walls betterOnly three non-overlapping channels, crowded, interference from Bluetooth and microwave ovens
5 GHzMany more channels, wider channels possibleShorter range
6 GHz (Wi-Fi 6E and Wi-Fi 7)Lots of clean spectrumShortest range; requires WPA3 or Enhanced Open, WPA2 is not allowed
  • SSID: the network name users see. BSSID: the MAC address of one AP radio for that SSID. ESS: one SSID served by many APs, so clients can roam.
  • More transmit power is not better: it causes co-channel interference and "sticky" clients that cling to a distant AP.
Hinglish mein samjho

Wi-Fi half duplex radio hai, ek channel pe ek time pe ek hi device bolta hai. 2.4 GHz mein sirf 1, 6 aur 11 non-overlapping. 5 GHz mein zyaada channels, range kam. 6 GHz mein WPA3 zaroori. SSID naam hai, BSSID AP radio ka MAC, ESS ek SSID kai APs pe. Zyaada power achhi nahi.

3.13.02

Autonomous, lightweight and cloud managed APs

AP architectures
ArchitectureHow it is managedTypical use
AutonomousEach AP configured on its ownA home or very small office
Lightweight (split MAC)APs join a wireless LAN controller (WLC) with CAPWAP; the WLC holds the configuration, security and RF decisionsCampuses and enterprises
Cloud managedAPs report to a cloud dashboard (for example Cisco Meraki)Many small sites with little local IT
Common AP modes
AP modeWhat it does
LocalDefault: serves clients, tunnels their traffic to the WLC
FlexConnectServes clients and can switch their traffic locally, useful for branches over a WAN
MonitorOnly listens: rogue detection, location, no clients
SnifferCaptures frames and sends them to an analyser
Rogue detectorWatches the wired side to spot rogue APs
Bridge / meshLinks APs wirelessly
SE-ConnectSpectrum analysis for interference

Wiring follows from the mode. A local mode AP sits on an access port, because client VLANs travel inside the CAPWAP tunnel. A FlexConnect AP often needs a trunk, because it drops client traffic onto local VLANs. The WLC connects with a trunk carrying its management and client VLANs, and several WLC ports can be bundled with LAG, which on AireOS controllers is a static bundle with no LACP or PAgP negotiation (channel-group N mode on on the switch).

Hinglish mein samjho

Autonomous AP alag alag configure hote hain. Lightweight APs CAPWAP (UDP 5246 control DTLS ke saath, 5247 data) se WLC se judte hain, config aur security WLC pe. Cloud managed jaise Meraki dashboard se. Local mode AP access port pe, FlexConnect aksar trunk pe, WLC trunk pe. AireOS WLC ka LAG static hai, switch pe mode on.

3.13.03

WPA, WPA2 and WPA3

Wi-Fi security generations
WPAWPA2WPA3
EncryptionTKIP (deprecated)AES-CCMPAES (CCMP or GCMP)
Personal modePre-shared keyPre-shared key (PSK)SAE, which resists offline password guessing
Enterprise mode802.1X802.1X with a RADIUS server802.1X, with an optional 192-bit mode
Protected management framesNoOptionalRequired

Personal means everyone shares one passphrase. Enterprise means each user or device authenticates individually through 802.1X to a RADIUS server, so one person can be removed without changing everyone's key. A shared PSK is the wrong choice for a large company. Wi-Fi Enhanced Open (OWE), certified alongside WPA3, encrypts open guest networks without a password.

How attackers abuse this

The evil twin: in a cafe, airport or railway station, an attacker broadcasts the same SSID as the real free Wi-Fi, sometimes with a fake login page asking for a phone number, OTP or card details. Deauthentication frames can knock people off the real network so their devices reconnect to the fake one. Separately, a WPA2 PSK handshake captured over the air can be attacked offline if the passphrase is weak. Inside companies, an employee plugging a cheap AP into a wall port creates a rogue back door.

Defender move

WPA3 or 802.1X with proper server certificate validation; protected management frames (PMF, 802.11w) to stop forged deauthentication; long passphrases; rogue detection on the WLC plus port security or 802.1X on wall ports; HTTPS only admin access to the WLC from the management VLAN. For users: confirm the network name with staff, never enter OTPs or card details on a Wi-Fi login page, and use mobile data or a trusted VPN for anything sensitive. Hiding the SSID and MAC filtering are not security controls: hidden SSIDs still appear in probe frames, and MACs are easy to copy.

Hinglish mein samjho

WPA TKIP deprecated. WPA2 AES-CCMP, PSK ya 802.1X. WPA3 Personal mein SAE (offline guessing se bachata hai), PMF zaroori. Enterprise mein har user RADIUS se authenticate hota hai. Evil twin: station ya cafe mein same naam ka fake Wi-Fi, login page pe OTP ya card maangta hai. Defence: WPA3/802.1X, PMF, lambe passphrase, rogue detection, aur users kabhi Wi-Fi login page pe OTP na daalein. Hidden SSID aur MAC filtering security nahi hain.

3.13.04

Building a WLAN in the WLC GUI

WLAN on an AireOS WLC, step by step

Use Next or the arrow keys. Menu names are from AireOS 8.x; Packet Tracer's WLC may differ.

    Log in

    Browse to the management address, for example https://192.168.99.10, from a PC in the management VLAN and sign in.

    Dynamic interface for the clients

    Controller > Interfaces > New: name it (for example wifi-clients), VLAN 50, IP 192.168.50.10/24, gateway 192.168.50.1, primary DHCP server 192.168.99.5. This is where client traffic leaves the WLC onto the wired network.

    Create the WLAN

    WLANs > Create New > Go: type WLAN, profile name and SSID CWM-Staff. On the General tab, set Status to Enabled and the interface to wifi-clients.

    Layer 2 security

    Security > Layer 2: WPA+WPA2, tick WPA2 Policy with AES encryption, set Authentication Key Management to PSK, and enter an ASCII passphrase of at least 12 characters (the WLC accepts 8 to 63). For Enterprise you would choose 802.1X and point the AAA Servers tab at RADIUS.

    QoS

    QoS tab: Platinum for voice, Gold for video, Silver for best effort (the default), Bronze for background traffic.

    Advanced

    Advanced tab: session timeout, client exclusion after repeated failures, and the PMF (management frame protection) setting.

    Apply and check

    Apply, then watch Wireless > All APs for joined APs and Monitor > Clients for associated clients and their VLAN 50 addresses.

    Hinglish mein samjho

    WLC GUI mein: management IP pe login, Controller > Interfaces > New se VLAN 50 ka dynamic interface, WLANs > Create New se SSID, Security > Layer 2 mein WPA2 AES PSK, QoS mein Silver ya voice ke liye Platinum, Advanced mein session timeout aur PMF, phir APs aur clients monitor karo.

      Hands-on lab

      Cisco Packet Tracer lab60 minutessimulated network

      Packet Tracer lab 3.13: WLC-2504 with lightweight APs and a WPA2 PSK WLAN

      You need: Cisco Packet Tracer (free with a Cisco Networking Academy account; version 9.0.1 was the current download on the NetAcad Resource Hub when this lesson was written). Devices: 1 x WLC-2504, 1 x 3650-24PS (PoE for the APs; add a power supply in its Physical tab if it stays off), 2 x lightweight APs (model names vary by version, for example LAP-PT or 3702i; UNVERIFIED for your build), 1 x Server-PT, 1 x PC-PT, 1 x Laptop-PT with a wireless module, 1 x Smartphone-PT.

      Simulator lab, zero risk. This lab runs inside Cisco Packet Tracer, so it touches no real network. Packet Tracer is free with a Cisco Networking Academy account (netacad.com). It simulates a subset of Cisco IOS, so where support for a feature is uncertain we say so instead of promising it works.

      2. DHCP server pools

        On Server-DHCP, Services, DHCP: one pool for 192.168.99.0/24 (gateway .1, start .100) for the APs, and one for 192.168.50.0/24 (gateway .1) for clients.

      3. WLC management

        Set the WLC management interface to 192.168.99.10/24, gateway 192.168.99.1, VLAN 99. Whether Packet Tracer expects that VLAN tagged or untagged by default is UNVERIFIED; if the WLC is unreachable, try the other choice to match the switch trunk's native VLAN.

      4. WLC GUI

        From Admin-PC, browse to https://192.168.99.10 and log in. Follow the stepper in this lesson: dynamic interface for VLAN 50 (192.168.50.10, gateway .1, DHCP 192.168.99.5), WLAN CWM-Staff on that interface, WPA2 with AES and PSK, a passphrase of at least 12 characters, QoS Silver, enabled.

      5. APs and clients

        Wait for both APs to get VLAN 99 addresses and join (Wireless, All APs). On Laptop1 and Smartphone1, connect to CWM-Staff with WPA2-Personal, AES and the passphrase. They should get 192.168.50.x addresses.

      6. Discuss

        Without Packet Tracer: what would change for WPA3-Personal (SAE, PMF required) and for WPA3-Enterprise (802.1X against RADIUS)? Where would Platinum QoS be used?

      7. Verify

        DSW1#show interfaces trunk
DSW1#show power inline
DSW1#show vlan brief
Laptop1>ipconfig
Laptop1>ping 192.168.50.1

        On the WLC: Monitor, Summary for AP and client counts; Monitor, Clients for each client's SSID and address.

      You are done when: Both APs show as registered under Wireless, All APs; Laptop1 and Smartphone1 are associated to CWM-Staff with 192.168.50.x addresses and can ping 192.168.50.1; DSW1 shows PoE on Gi1/0/2 and Gi1/0/3 and a trunk on Gi1/0/1 allowing 50 and 99.

      Packet Tracer limits and notes

      • The APs must reach the WLC: here they share its subnet, which avoids needing DHCP option 43 or DNS discovery.
      • The WLC-2504 GUI exists in Packet Tracer and supports WLAN creation with WPA2 PSK in the outline author's experience, but some menus are greyed out or missing compared with real AireOS. Which ones, per version, is UNVERIFIED.
      • WPA3 in Packet Tracer is UNVERIFIED and probably unsupported on its end devices and the WLC-2504, so WPA3 is taught as concept here. Rogue detection, PMF settings and LAG on the Packet Tracer WLC are also UNVERIFIED.
      • Whether Packet Tracer's WLC-2504 offers a CLI for these steps is UNVERIFIED; the GUI is what the exam topics ask for. Some 8.x builds have also offered a WLC-3504 and Meraki devices: UNVERIFIED.
      • Packet Tracer simulates a subset of IOS. If a command here is rejected in your version, note it, skip that step and carry on; the concept still applies to real Cisco gear.

      Key takeaways

      • Use channels 1, 6 and 11 in 2.4 GHz, and prefer 5 GHz or 6 GHz where you can.
      • Lightweight APs tunnel to a WLC with CAPWAP.
      • Local mode AP on an access port; FlexConnect and WLC on trunks; AireOS LAG is static.
      • Build WLANs in the GUI: interface, SSID, Layer 2 security, QoS, advanced.
      • WPA3 brings SAE and mandatory PMF; Enterprise beats a shared key.
      • Teach users about evil twins: never type an OTP into a Wi-Fi login page.
