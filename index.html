04 / tools

          
Free browser-only security tools

          
Educational tools. Everything runs in your browser: nothing you type is sent anywhere or saved.

        

        

          
          
          
          
        

        

        

          

            
Subnet calculator network

            
Enter an IPv4 address with CIDR prefix, e.g. 192.168.1.10/24. Runs entirely in your browser.

          

          

            
            
            
          

          

          

        


          

            

              
Password strength offline

              
Estimates how long a guessing attack would take. Never sent, never stored. Better: test a password that's similar to yours, not the real one.

            

            
            

              
              
            

            

            

          


          

            

              
Hash identifier offline

              
Paste a hash to guess its type from length, characters and prefix.

            

            
            
            

          


          

            

              
Is this link suspicious? offline

              
Paste a link from an SMS, WhatsApp or email. It is only read as text; it is never opened. A clean result doesn't mean safe, so still check the checklist.

      Everything here is for learning and defence. Only test systems you own or have explicit written authorisation to test. Unauthorised access, data theft or damage to computer systems is an offence in India under the Information Technology Act, 2000 (e.g. Sections 43 and 66) and can lead to fines and imprisonment.
