3.6.01

Three ways to route between VLANs

VLANs separate hosts at Layer 2. To let VLAN 10 reach VLAN 20 at all, something must route between their subnets, and every PC needs that device as its default gateway.

Inter-VLAN routing methods
MethodHowGood forWatch out
LegacyOne router interface per VLANTeaching onlyBurns router ports and switch ports.
Router on a stickOne trunk to a router, one subinterface per VLANSmall sites, labsAll inter-VLAN traffic shares one physical link.
Layer 3 switchip routing plus an SVI per VLANMost campus networksRouting happens in switch hardware at full speed; filter it with ACLs.
Defender move

The inter-VLAN router is your first internal choke point. It is where you put ACLs (lesson 3.9) so guests reach the internet but not staff, and so a compromised laptop cannot reach management interfaces. A VLAN without filtering at its gateway is only half a boundary.

Hinglish mein samjho

VLAN 10 se VLAN 20 tak jaane ke liye routing chahiye aur har PC ka default gateway woh router hota hai. Teen tareeke: legacy (har VLAN ka alag port), router on a stick (ek trunk, subinterfaces), Layer 3 switch (ip routing + SVI). Gateway pe ACL lagao, warna VLAN aadhi boundary hai.

3.6.02

Router on a stick

R1(config)#interface GigabitEthernet0/0/0
R1(config-if)#no shutdown
R1(config-if)#interface GigabitEthernet0/0/0.10
R1(config-subif)#encapsulation dot1Q 10
R1(config-subif)#ip address 192.168.10.1 255.255.255.0
R1(config-subif)#interface GigabitEthernet0/0/0.20
R1(config-subif)#encapsulation dot1Q 20
R1(config-subif)#ip address 192.168.20.1 255.255.255.0
R1(config-subif)#interface GigabitEthernet0/0/0.99
R1(config-subif)#encapsulation dot1Q 99 native
  • encapsulation dot1Q must come before the IP address on a subinterface.
  • The physical interface needs no shutdown; the subinterfaces follow it. The subinterface number does not have to match the VLAN, but matching it saves confusion.
  • The native VLAN subinterface uses the native keyword so it matches the switch's untagged VLAN 99.
  • The switch side is a normal trunk: switchport mode trunk, native 99, allowed 10,20,99.
Hinglish mein samjho

Router on a stick: switch ka ek trunk router ke ek physical port pe, aur router pe har VLAN ka subinterface (Gi0/0/0.10). Pehle encapsulation dot1Q 10, phir IP. Physical port pe no shutdown. Native VLAN subinterface pe native keyword.

3.6.03

Layer 3 switch SVIs and routed ports

DSW1(config)#ip routing
DSW1(config)#interface vlan 10
DSW1(config-if)#ip address 192.168.10.1 255.255.255.0
DSW1(config-if)#no shutdown
DSW1(config-if)#interface vlan 20
DSW1(config-if)#ip address 192.168.20.1 255.255.255.0
DSW1(config-if)#no shutdown
! a routed uplink to a router, no VLANs involved:
DSW1(config)#interface GigabitEthernet1/0/24
DSW1(config-if)#no switchport
DSW1(config-if)#ip address 10.0.0.1 255.255.255.252
  • Forget ip routing and the SVIs come up but nothing routes between them. It is the most common mistake in this topic.
  • An SVI is only up/up if its VLAN exists and at least one port in that VLAN (access or trunk) is up and forwarding.
  • no switchport turns a switch port into a router port with its own IP, used for point to point links to routers or other Layer 3 switches.
Hinglish mein samjho

Layer 3 switch pe ip routing on karo, har VLAN ka SVI (interface vlan 10) IP ke saath. ip routing bhool gaye toh SVIs up honge par routing nahi hogi. SVI up/up tabhi jab VLAN exist kare aur uska koi port up ho. no switchport se port router port ban jaata hai.

3.6.04

First hop redundancy: HSRP

Every host has one default gateway address. If that router dies, the hosts are cut off even if a second router is sitting right there. A first hop redundancy protocol lets two or more routers share a virtual gateway IP and MAC, so hosts never notice which router is doing the work.

HSRP versions
HSRP version 1HSRP version 2
Groups0 to 2550 to 4095
Hellos to224.0.0.2, UDP 1985224.0.0.102, UDP 1985
Virtual MAC0000.0c07.acXX (XX = group)0000.0c9f.fXXX (XXX = group)
IPv6NoYes
  • Highest priority becomes active (default 100; a tie goes to the highest interface IP). Hellos every 3 seconds; the standby takes over after the 10 second hold time by default.
  • Preempt is off by default. Without standby 1 preempt, a recovered primary router will not take its role back.
  • Alternatives: VRRP (open standard, RFC 5798, master and backup, preempt on by default) and GLBP (Cisco, shares the load across several routers at once).
R-A(config)#interface GigabitEthernet0/1
R-A(config-if)#ip address 192.168.100.2 255.255.255.0
R-A(config-if)#standby version 2
R-A(config-if)#standby 1 ip 192.168.100.1
R-A(config-if)#standby 1 priority 110
R-A(config-if)#standby 1 preempt
R-A#show standby brief
How attackers abuse this

HSRP hellos are multicast on the LAN. A host that sends forged hellos with priority 255 can become the active gateway and receive everyone's outbound traffic: a man in the middle, or a black hole.

Defender move

Use HSRP authentication with MD5 (standby 1 authentication md5 key-string ...), run HSRP only on interfaces that need it, and alert on unexpected state changes in logs. Packet Tracer support for HSRP MD5 authentication is UNVERIFIED.

Hinglish mein samjho

Host ka ek hi gateway hota hai; woh router gira toh sab cut. HSRP mein do routers ek virtual IP aur MAC share karte hain. Highest priority active (default 100). Preempt default off hai, isliye standby 1 preempt lagao. v2 mein 4096 groups aur IPv6. VRRP open standard, GLBP load share. Attacker priority 255 hellos bhej ke gateway ban sakta hai; MD5 authentication lagao.

    1. Part A: switch side

      SW1(config)#interface Gi0/1
SW1(config-if)#switchport mode trunk
SW1(config-if)#switchport trunk native vlan 99
SW1(config-if)#switchport trunk allowed vlan 10,20,99

    2. Part A: router subinterfaces

      R1(config)#interface Gi0/0/0
R1(config-if)#no shutdown
R1(config-if)#interface Gi0/0/0.10
R1(config-subif)#encapsulation dot1Q 10
R1(config-subif)#ip address 192.168.10.1 255.255.255.0
R1(config-subif)#interface Gi0/0/0.20
R1(config-subif)#encapsulation dot1Q 20
R1(config-subif)#ip address 192.168.20.1 255.255.255.0
R1(config-subif)#interface Gi0/0/0.99
R1(config-subif)#encapsulation dot1Q 99 native

      Ping PC-Guest from PC-Staff. It should work now, which is exactly why lesson 3.9 adds an ACL.

    3. Part B: Layer 3 switch

      DSW1(config)#ip routing
DSW1(config)#interface vlan 10
DSW1(config-if)#ip address 192.168.10.1 255.255.255.0
DSW1(config-if)#no shutdown
DSW1(config-if)#interface vlan 20
DSW1(config-if)#ip address 192.168.20.1 255.255.255.0
DSW1(config-if)#no shutdown
DSW1(config-if)#interface Gi1/0/24
DSW1(config-if)#no switchport
DSW1(config-if)#ip address 10.0.0.1 255.255.255.252

      Then remove ip routing and test again, to see the classic failure for yourself. Put it back.

    4. Part C: HSRP on R-A

      R-A(config)#interface G0/1
R-A(config-if)#ip address 192.168.100.2 255.255.255.0
R-A(config-if)#no shutdown
R-A(config-if)#standby version 2
R-A(config-if)#standby 1 ip 192.168.100.1
R-A(config-if)#standby 1 priority 110
R-A(config-if)#standby 1 preempt

    5. Part C: HSRP on R-B

      R-B(config)#interface G0/1
R-B(config-if)#ip address 192.168.100.3 255.255.255.0
R-B(config-if)#no shutdown
R-B(config-if)#standby version 2
R-B(config-if)#standby 1 ip 192.168.100.1
R-B(config-if)#standby 1 preempt

    6. Fail over

      From the PC run ping -t 192.168.100.1, then shut R-A's G0/1. Watch R-B become active, then bring R-A back and watch it preempt. Run arp -a on the PC: the gateway's MAC is the HSRP virtual MAC, not a router's own.

    7. Verify

      R1#show ip interface brief
R1#show ip route
DSW1#show ip route
DSW1#show interfaces vlan 10
R-A#show standby brief
R-A#show standby

    You are done when: PCs in VLAN 10 and 20 ping each other through R1 and then through DSW1; show standby brief shows R-A Active and R-B Standby, and the roles swap and swap back when R-A's link is shut and restored.

    Packet Tracer limits and notes

    • Some Packet Tracer guides use encapsulation dot1Q 99 native on the ISR4331; support on every image is UNVERIFIED. If rejected, leave VLAN 99 off the router.
    • HSRP on the Packet Tracer 3650 is UNVERIFIED, which is why Part C uses 2911 routers. VRRP and GLBP are UNVERIFIED in Packet Tracer and are theory only here.
    • Cisco NetAcad publishes official Packet Tracer activities for router on a stick inter-VLAN routing if you want more practice.
    • Packet Tracer simulates a subset of IOS. If a command here is rejected in your version, note it, skip that step and carry on; the concept still applies to real Cisco gear.

    Key takeaways

    • Every VLAN needs a gateway that routes and, ideally, filters.
    • Router on a stick: dot1Q subinterfaces over one trunk.
    • Layer 3 switch: ip routing plus SVIs; no switchport for routed links.
    • HSRP gives hosts a virtual gateway; configure preempt deliberately.
    • Authenticate FHRP hellos where you can.
