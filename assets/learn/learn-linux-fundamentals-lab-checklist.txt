CyberWithMadhav Learn: lesson 2.1 lab checklist
Lab: theory into muscle memory
https://www.cyberwithmadhav.com/learn-linux-fundamentals.html

Time: 30 minutes
You need: Your Ubuntu VM. The full hands-on lab is lesson 2.2; this one checks the theory.

STEPS (tick each box when done)
[ ] 1. Walk the tree
      $ cd / && ls
      $ ls -la /etc | head -20
      $ ls /var/log
      $ cat /proc/version
      Note: For each top level folder, say in one line what it holds without looking at this page.
[ ] 2. Read the account files
      $ cat /etc/passwd
      $ awk -F: '$3==0' /etc/passwd
      $ sudo head -3 /etc/shadow
      $ getent group sudo
      Note: Count accounts with a real login shell versus nologin. Check that only root has UID 0. Note the $y$ hash prefix.
[ ] 3. Audit permissions
      $ find / -perm -4000 -type f 2>/dev/null
      $ sudo -l
      $ ls -ld /tmp
      Note: Write down the SUID programs you find (passwd, sudo, su and mount are normal) and the t at the end of /tmp's permissions.
[ ] 4. Check persistence spots on your own VM
      $ crontab -l
      $ ls /etc/cron.d /etc/cron.daily
      $ systemctl list-unit-files --state=enabled | head -30
      $ ls -la ~/.ssh 2>/dev/null
      Note: This is the baseline of a clean machine. Save the output to a file; comparing against a baseline is how you spot changes later.

DONE WHEN: You can explain the purpose of each top level folder, read a passwd line, convert a permission string to octal, and list where Linux persistence hides.

Only on machines you own. Testing systems without written permission can be an offence under the IT Act, 2000.
