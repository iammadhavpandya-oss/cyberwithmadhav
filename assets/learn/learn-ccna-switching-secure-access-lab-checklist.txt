CyberWithMadhav Learn: lesson 3.3 lab checklist
Packet Tracer lab 3.3: baseline hardening and a MAC table study
https://www.cyberwithmadhav.com/learn-ccna-switching-secure-access.html

Time: 40 minutes
You need: Cisco Packet Tracer (free with a Cisco Networking Academy account; version 9.0.1 was the current download on the NetAcad Resource Hub when this lesson was written). Devices: 2 x 2960-24TT, 1 x ISR4331, 5 x PC-PT. Everything stays in VLAN 1 for now; VLANs arrive in lesson 3.4.

ADDRESSING
  R1 | Gi0/0/0 | 192.168.1.1/24 | 
  SW1 | VLAN 1 | 192.168.1.2/24 | gw 192.168.1.1
  SW2 | VLAN 1 | 192.168.1.3/24 | gw 192.168.1.1
  PC1 to PC4 | Fa0 | 192.168.1.11 to .14/24 | gw 192.168.1.1
  Admin-PC | Fa0 | 192.168.1.50/24 | gw 192.168.1.1

STEPS (tick each box when done)
[ ] 1. Watch the MAC table fill
      SW1# clear mac address-table dynamic
      SW1# show mac address-table
      SW1# show mac address-table
      Note: PC3 and PC4 appear against Gi0/1: many MACs behind one port.
[ ] 2. Baseline SW1 (repeat on SW2 and R1 with their own names and addresses)
      SW1(config)# hostname SW1
      SW1(config)# no ip domain-lookup
      SW1(config)# enable secret Cwm#Enable2026
      SW1(config)# service password-encryption
      SW1(config)# banner motd # Authorised access only. Activity is logged. #
      SW1(config)# username netadmin secret Cwm#Admin2026
      SW1(config)# line console 0
      SW1(config-line)# login local
      SW1(config-line)# exec-timeout 5 0
      SW1(config-line)# exit
      SW1(config)# interface vlan 1
      SW1(config-if)# ip address 192.168.1.2 255.255.255.0
      SW1(config-if)# no shutdown
      SW1(config-if)# exit
      SW1(config)# ip default-gateway 192.168.1.1
[ ] 3. SSH only
      SW1(config)# ip domain-name cyberwithmadhav.lab
      SW1(config)# crypto key generate rsa
      SW1(config)# ip ssh version 2
      SW1(config)# line vty 0 15
      SW1(config-line)# login local
      SW1(config-line)# transport input ssh
[ ] 4. Test from Admin-PC
      Note: In Admin-PC's Command Prompt: ssh -l netadmin 192.168.1.2 should log in. Then telnet 192.168.1.2 should be refused or closed.
[ ] 5. Neighbours and unused ports
      SW1# show cdp neighbors
      SW1(config)# lldp run
      SW1# show lldp neighbors
      SW1(config)# interface range Fa0/1 - 3
      SW1(config-if-range)# no cdp enable
      SW1(config-if-range)# interface range Fa0/4 - 23
      SW1(config-if-range)# shutdown
[ ] 6. Verify and save
      SW1# show ip ssh
      SW1# show ssh
      SW1# show running-config | section line vty
      SW1# show interfaces status
      SW1# copy running-config startup-config

DONE WHEN: SSH from Admin-PC works and Telnet fails, show ip ssh reports version 2.0, unused ports show disabled, and the MAC table shows PC3 and PC4 behind Gi0/1.

PACKET TRACER LIMITS AND NOTES
  - Some Packet Tracer images accept only line vty 0 15 on switches and line vty 0 4 on some routers. Use what the device accepts. UNVERIFIED for every model.
  - An RSA modulus of 2048 is accepted by recent Packet Tracer versions in common lab guides, but this is UNVERIFIED for every image. If rejected, use the largest value offered (at least 1024).
  - LLDP on Packet Tracer's 2960 and ISR models: UNVERIFIED for every build. login block-for exists in IOS; Packet Tracer support UNVERIFIED.
  - enable algorithm-type scrypt secret (type 9) is real IOS; Packet Tracer support UNVERIFIED.

Packet Tracer is free with a Cisco Networking Academy account: https://www.netacad.com/
